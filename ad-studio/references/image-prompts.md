# Image prompts (any generator: Google Flow, ChatGPT, Gemini, Midjourney…)

Write every prompt complete and standalone. Generate one image per prompt to save credits. Ask for plain backgrounds when the image will be cut out.

## Product with its name
```
Studio product photograph, square 1:1. A [matte black kraft coffee bag with a gold label] standing upright on a plain warm cream background, soft diffused light from the left, gentle shadow. The label clearly reads "[BRAND NAME]" in large elegant [Arabic/Latin] letters and below it "[TAGLINE]" in smaller letters, all text spelled exactly as written, sharp and readable. A few [cardamom pods and coffee beans] at the base. Premium minimal packaging design, photorealistic, no other text, no logos.
```
Check the spelling in the result. Regenerate if any letter is wrong.

## Character sheet (4 expressions)
```
Character expression sheet, 2x2 grid on a plain light cream background. The same [elderly Emirati grandmother wearing a black shayla and a golden burqa face mask] in four bust portraits: skeptical with one raised eyebrow, shocked with open mouth, laughing warmly, eyes closed smiling as if smelling something lovely. Identical face, outfit, colours and art style in all four. Warm illustrated style with soft shading, clean outlines, no text.
```

## Story / moment cards (portrait 3:4)
```
Editorial lifestyle photograph, vertical 3:4. [Scene description: who, where, what object is in sharp focus]. [Light: soft morning light / warm evening lamp light / golden hour]. Warm cream, beige and soft gold palette with subtle [brand accent] accents, shallow depth of field, premium advertising style, photorealistic, no text, no logos.
```
If people appear, respect the audience: e.g. only women in modest abayas and hijab for a family gathering, or hands only. State "no men" or "no faces" explicitly when needed.

## Hands
```
Close-up of a woman's hand with a modest long black sleeve [action, e.g. pouring Arabic coffee from a golden dallah into a small white cup], [background softly blurred], warm natural light, photorealistic, no face, no text.
```
