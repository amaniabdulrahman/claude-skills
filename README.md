## كيف تضيفون المهارة

**١. حمّلوا الملف المضغوط للمهارة اللي تبونها:**
- [quran-video-maker.zip](downloads/quran-video-maker.zip)
- [ad-studio.zip](downloads/ad-studio.zip)
(افتحوا الرابط واضغطوا زر التحميل)

**٢. في تطبيق Claude:**
افتحوا صفحة Customize، ثم تبويب Skills، واضغطوا Add، وارفعوا الملف المضغوط.

**٣. في Claude Code:**
فكّوا الضغط وحطوا مجلد المهارة (مثل `quran-video-maker` أو `ad-studio`) داخل مجلد المهارات:
`~/.claude/skills/`

**٤. جربوها:**
اكتبوا لـ Claude: «سوّ لي فيديو قرآني» أو «سوّ لي إعلان لمنتجي»
